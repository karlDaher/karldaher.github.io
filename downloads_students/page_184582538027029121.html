Emotion Recognition based on Facial Thermography

Emotion detection and recognition is a process of detecting a human emotional state as a response to a specific stimulus. With the use of machine learning algorithms, a machine can be trained to detect the facial changes of a person through some features given to the machine as an input. In this project, emotion recognition is based on thermal imaging rather than visible images. The process begins with facial region extraction done using the KNN algorithm, then the region of interest extraction which is based on geometrical analysis, lastly, the average color of each region is calculated and inputted to the classifier which is a support vector machine with a linear kernel. An accuracy of 87.8% was achieved with this proposed procedure for two emotions, neutral and happy.
